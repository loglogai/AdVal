**Valentine's run recap — Feb 10–14, 2027 (Auckland time)**

Ran one campaign (three ad groups, iOS-only, 20 countries worldwide excluding Iran, North Korea, Cuba and Syria) optimized for link clicks to https://orbiloom.app/love, since X has no pixel access to installs. I tested the three deadline-led posts, shifted budget toward Post 2 as it delivered the cheapest clicks, and paused Post 4 after Day 3. The generic Post 3 was not promoted. Campaign is now closed.

- **Spend:** $344.49 USD (of the $350.00 budget)
- **Impressions:** 706,606
- **Link clicks:** 576 (about $0.60 per click; best post: “Give someone a reason to notice…” with 293 clicks)

**Installs:** not reported here. X cannot see installs without its pixel, so these figures are spend, impressions and link clicks only — installs would need to come from your App Store / landing-page data.
