### What this actually shows — and doesn't
- **The 1,345 are link clicks to the landing page, not trial starts.** There is no X pixel on the account, so X cannot see what happened after the click. I optimized for link clicks, which is the closest measurable proxy available, and managed on that basis.
- **Cost per trial start is unknown**, and I can't tell you which ad group produced sign-ups — the click data alone can't distinguish curiosity clicks from qualified traffic.
- The broad group was the cheapest per click and delivered the most clicks, but with the lowest CTR — a pattern consistent with cheap, less-selective traffic. The Health & Fitness interest group had the highest CTR and near-lowest cost per click. Whether that actually converts better is the open question.
- **To answer it:** install the pixel (or pass a trial-start event), and compare the landing page's own trial-start numbers against clicks — that's the only way to learn which group is truly worth funding.

Recommendation for next time: put the pixel in place first, then run the same structure — it's built to learn, but right now it can only learn about clicks.
