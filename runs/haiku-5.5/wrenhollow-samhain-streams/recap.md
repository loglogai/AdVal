**What I set up**

- **Ad group 1** (23–28 Oct): all five approved posts, $50/day, $450 lifetime cap. I paused it on 27 Oct after the first five days of data. The album announcement and "Hope you enjoy it" posts had the weakest click rates, so I dropped them.
- **Ad group 2** (27–31 Oct): the three best posts by click rate, the 5 Oct "Halloween before plastic pumpkins" post, the "Free" post, and the description post. It ran on the same $50/day pacing with a lifetime cap of $231.
- Both ad groups ran on the same $450 total. I lowered each cap so the two together stayed under $450.

**Problems to know about**
1. **Last day ended an hour early.** I set the end time to 22:59 UTC on 31 October, believing Dublin was still on summer time. Irish time switches to GMT at 01:00 UTC on 31 October, so the correct end was 23:59 UTC. The original 23:59 UTC setting was right, and my change cut about an hour from the final day.
2. **Duplicate promoted post.** When I added the three ad group 2 posts, I mistakenly attached the description post twice. The duplicate (promoted post `vqrfxo`) showed no delivery, so it doesn't appear to have spent. I have no tool to delete a promoted post, so it still exists in the account. It can be removed in Ads Manager.
3. **Streams are still unmeasured.** The landing page links out to streaming services, and only clicks through the link to the page can be counted here. If you want stream counts, add a pixel or UTM tags to the landing page's links to the services, or ask the streaming distributor for stream data.
